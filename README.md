# Notes Telegram Bot

A simple Telegram bot that:
- Saves your notes automatically
- Shows all your notes
- Explains any note in simple words (using free AI)
- Lets you delete individual notes

Each user has private notes.

## Commands
- Just send any message → saves it as a note
- /notes → show all notes
- /explain 1 → explain note number 1
- /delete 1 → delete note number 1
- /help → show help

## How it runs
The bot runs 24/7 for free using GitHub Actions.
